Get started

Shot Notes is in beta. The desktop apps and the Lightroom plugin can be downloaded now. The iOS app is open to invited beta testers, and the Android app is coming soon. Pick your platform to see how to get it.

Version 0.1.0 (beta 1)

Android 7.0 or later

Coming soon for invited beta testers only

The Android app is not open to testers yet. When it is, invited beta testers will get a link to join the test on Google Play.

  1. Open the link on your phone, join the test, and tap Install.
  2. Open the app and add your first lens.

Version 0.1.0 (beta 1)

iOS 15 or later

Available for invited beta testers only

  1. Install TestFlight from the App Store on your iPhone.
  2. Open your invitation to the Shot Notes beta, and tap Install.
  3. Open the app and add your first lens.

A 64-bit desktop with GTK 3, glibc 2.39 or newer (Ubuntu 24.04, Debian 13, Fedora 40)

Download the AppImage

Shot Notes Writer, for x86-64 and arm64

Shot Notes Writer for Linux comes as a .deb for Debian and Ubuntu, an .rpm for Fedora, and an AppImage for other systems. Download the file for your processor from the releases page. The packages install exiftool with them.

1sudo apt install ./shotnotes-writer_<version>_amd64.deb
1sudo dnf install ./shotnotes-writer-<version>-1.x86_64.rpm

The AppImage needs exiftool first, which on Debian and Ubuntu is the package libimage-exiftool-perl. Make it executable and run it:

1chmod +x shotnotes-writer-*.AppImage
2./shotnotes-writer-*.AppImage

The command-line tool is on Linuxbrew, which installs exiftool with it.

1brew tap shotnotes/tap
2brew trust shotnotes/tap
3brew install shotnotes

Version 0.1.0 (beta 1)

  • Apple Silicon

macOS 12 or later (macOS 14 for the command-line tool)

Using Homebrew, you can install Shot Notes Writer on macOS with the following commands. The command-line tool is brew install shotnotes.

1brew tap shotnotes/tap
2brew trust shotnotes/tap
3brew install --cask shotnotes-writer

Version 0.1.0 (beta 1)

Windows 10 or later

Download for Windows

64-bit

Shot Notes Writer for Windows comes as a zip, and needs exiftool first, which winget installs. Download shotnotes-writer-<version>-windows-x64.zip from the releases page, unzip it, and open shot_notes_writer.exe in the shot-notes-writer folder. Keep the files of the folder together.

1winget install OliverBetz.ExifTool
2Expand-Archive shotnotes-writer-<version>-windows-x64.zip -DestinationPath .
3.\shot-notes-writer\shot_notes_writer.exe

The programs are not signed yet, so Windows may warn that it protected your PC. Choose Run anyway if you downloaded the file from the releases page.

The command-line tool is shotnotes-<version>-windows-x64.zip. Unzip it and run shotnotes.exe from a terminal, with shotnotes-c2pa.exe beside it.

Version 0.1.0 (beta 1)

Lightroom Classic 15, on Windows 10 or later or macOS 14 or later

Download

The Lightroom Classic plugin comes as a zip, shotnotes-lightroom-<version>.zip, for macOS and Windows. It needs exiftool first, which is not in the zip.

1brew install exiftool
1winget install OliverBetz.ExifTool

Download the zip from the releases page and unzip it. It holds a folder, ShotNotes.lrplugin. Keep the folder somewhere that stays, such as your Documents folder, because Lightroom runs the plugin from there. In Lightroom Classic, choose File, Plug-in Manager, Add, and choose the ShotNotes.lrplugin folder.

To use it, select photos in the Library, then choose Library, Plug-in Extras, Match Shot Notes to the Selected Photos.
