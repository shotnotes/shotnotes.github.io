The Shot Notes XMP namespace

https://shotnotes.app/ns/1.0/ is the name of a set of fields that Shot Notes writes into a photo’s XMP metadata, under the prefix shotnotes. This page describes them, so that other software can read them. It is version 1.0.

What it is for

Shot Notes puts a shot’s notes into the fields that photo software already shows: the lens, aperture, focal length, caption and place. It puts the shot in full into this namespace as well, so that nothing is lost, and so that a later write can tell that a file already has a shot’s notes. Software that wants the kit, or the note exactly as it was typed, can read it here.

The fields

FieldTypeHolds
shotnotes:IdtextThe shot's id, a UUID (version 7), which stays the same when the shot is exported again.
shotnotes:WritertextWho wrote the fields, such as "Shot Notes 1.0.0".
shotnotes:AperturerealThe f-number.
shotnotes:ShutterrealThe exposure time in seconds, if the shot has one.
shotnotes:IsointegerThe ISO, if the shot has one.
shotnotes:FocalLengthrealThe focal length in millimetres: the one of the lens that was used.
shotnotes:LensstructureThe lens.
ManufacturertextThe maker.
NametextThe name of the lens.
DescriptiontextA description, if recorded.
SerialNumbertextIts serial number, if recorded.
FocalLengthsreal, listThe focal lengths in millimetres that the lens offers: one for a prime lens, several for a lens with fixed settings.
ApertureWidestrealThe widest aperture, as an f-number, if recorded.
ApertureNarrowestrealThe narrowest aperture, as an f-number, if recorded.
shotnotes:LocationtextThe place, as the photographer wrote it.
shotnotes:CoordinatesstructureWhere the shot was taken, if recorded.
LatituderealDecimal degrees (WGS84), north positive, south negative.
LongituderealDecimal degrees (WGS84), east positive, west negative.
AltituderealMetres above mean sea level, negative below, if known. Rough when it came from a phone.
shotnotes:NotestextThe note, as the photographer wrote it.
shotnotes:InstanttextWhen the shot was taken, as a date and time in UTC (ISO 8601, ending in Z).
shotnotes:UtcOffsettextThe offset from UTC in force when it was taken, such as +01:00. The local time is Instant plus UtcOffset.
shotnotes:TimeZonetextThe name of the time zone, such as Europe/Lisbon.
shotnotes:Lightingstructure, listThe lights used, if any.
ManufacturertextThe maker.
NametextThe name of the item.
GuideNumbertextThe guide number as the maker states it, such as GN 40.
SerialNumbertextIts serial number, if recorded.
DescriptiontextA description, if recorded.
shotnotes:Filtersstructure, listThe filters used, if any.
ManufacturertextThe maker.
NametextThe name of the item.
ThreadSizerealThe thread diameter in millimetres.
SerialNumbertextIts serial number, if recorded.
DescriptiontextA description, if recorded.
shotnotes:Accessoriesstructure, listOther kit used, such as a grip or a strap.
ManufacturertextThe maker.
NametextThe name of the item.
SerialNumbertextIts serial number, if recorded.
DescriptiontextA description, if recorded.

A field with no value is absent. A structure’s own fields are written inside it. A list is an XMP bag, except the focal lengths, which are a sequence.

An example

<rdf:Description rdf:about=''
 xmlns:shotnotes='https://shotnotes.app/ns/1.0/'>
 <shotnotes:Aperture>5.6</shotnotes:Aperture>
 <shotnotes:Filters>
  <rdf:Bag>
   <rdf:li rdf:parseType='Resource'>
    <shotnotes:Manufacturer>B+W</shotnotes:Manufacturer>
    <shotnotes:Name>Circular Polariser</shotnotes:Name>
    <shotnotes:ThreadSize>52</shotnotes:ThreadSize>
   </rdf:li>
  </rdf:Bag>
 </shotnotes:Filters>
 <shotnotes:FocalLength>35</shotnotes:FocalLength>
 <shotnotes:Id>0199-test</shotnotes:Id>
 <shotnotes:Instant>2026-10-24T09:29:38.000Z</shotnotes:Instant>
 <shotnotes:Lens rdf:parseType='Resource'>
  <shotnotes:ApertureNarrowest>16</shotnotes:ApertureNarrowest>
  <shotnotes:ApertureWidest>1.4</shotnotes:ApertureWidest>
  <shotnotes:FocalLengths>
   <rdf:Seq>
    <rdf:li>35</rdf:li>
   </rdf:Seq>
  </shotnotes:FocalLengths>
  <shotnotes:Manufacturer>Voigtländer</shotnotes:Manufacturer>
  <shotnotes:Name>Nokton 35 mm f/1.4</shotnotes:Name>
 </shotnotes:Lens>
 <shotnotes:Notes>Rain on the tram</shotnotes:Notes>
 <shotnotes:TimeZone>Europe/Lisbon</shotnotes:TimeZone>
 <shotnotes:UtcOffset>+01:00</shotnotes:UtcOffset>
 <shotnotes:Writer>Shot Notes 1.0.0</shotnotes:Writer>
</rdf:Description>

Reading and writing it

Any software may read these fields, and write them, without asking. exiftool needs shotnotes.config to know them:

exiftool -config shotnotes.config -XMP-shotnotes:all photo.jpg

exiftool runs a config file as a program, so use only one you trust.

Versions

The number in the address is the version. A field in version 1.0 keeps its meaning and is not removed; software should ignore fields it does not know, since more may be added. A change that would alter what a field means gets a new address, https://shotnotes.app/ns/2.0/, so that a reader can tell the two apart.
